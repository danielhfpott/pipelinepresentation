# Agent Router

Read `CONTEXT_ENTRYPOINT.md` before making substantive project, code, presentation, or architecture decisions.

Verify the checked-out branch and commit before treating repository state as current. The active context branch may be newer than `main`.

Do not delete, reset, clean, move, rename, overwrite, force-push, or otherwise destructively normalize the workspace.

Do not let generated documentation outrank contradictory code/runtime/source evidence.

Write material reconciled findings back to GitHub so later agents inherit the same project state instead of creating parallel context.
